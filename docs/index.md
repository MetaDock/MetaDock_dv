# MetaDock Documentation

Welcome to the MetaDock documentation site.

This site provides setup, architecture, handover, prompt, evaluation, and platform usage guides for developers, reviewers, and operators.

## Current runtime entrypoints

- Node app: `npm start` -> `backend-node/server.js`
- Python agent (manual mode): `python backend-agent/api/agent_server.py`

## Recommended reading order

1. `setup-migration-guide.md` for project layout and startup instructions.
2. `handover-runbook.md` for one-page operational checks.
3. `architecture.md` for module boundaries and data flow.
4. `platform-user-guide.md` for user-facing role and feature behavior.
5. `prompt-assets.md` and `evaluation-guide.md` for experiment/reproducibility details.
