Usage:   roary [options] *.gff

Options:
  -p, INT
                        number of threads [1]
  -o, STR
                        clusters output filename
                        [clustered_proteins]
  -f, STR
                        output directory [.]
  -e
                        create a multiFASTA alignment of
                        core genes using PRANK
  -n
                        fast core gene alignment with
                        MAFFT, use with -e
  -i, INT
                        minimum percentage identity for
                        blastp [95]
  -cd, FLOAT
                        percentage of isolates a gene
                        must be in to be core [99]
  -qc
                        generate QC report with Kraken
  -k, STR
                        path to Kraken database for QC,
                        use with -qc
  -a
                        check dependancies and print
                        versions
  -b, STR
                        blastp executable [blastp]
  -c, STR
                        mcl executable [mcl]
  -d, STR
                        mcxdeblast executable
                        [mcxdeblast]
  -g, INT
                        maximum number of clusters
                        [50000]
  -m, STR
                        makeblastdb executable
                        [makeblastdb]
  -r
                        create R plots, requires R and
                        ggplot2
  -s
                        dont split paralogs
  -t, INT
                        translation table [11]
  -ap
                        allow paralogs in core alignment
  -z
                        dont delete intermediate files
  -v
                        verbose output to STDOUT
  -w
                        print version and exit
  -y
                        add gene inference information
                        to spreadsheet, doesnt work with
                        -e
  -iv, STR
                        Change the MCL inflation value
                        [1.5]
  -h
                        this help message
